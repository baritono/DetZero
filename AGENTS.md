# AGENTS.md

Standing conventions for coding agents (and humans) working in DetZero.
Procedures live in `docs/`; this file is the table of contents.

## Stack
- Python, PyTorch, NumPy; CUDA extensions under `utils/detzero_utils/ops/*/src`.
- Four packages, each with its own `setup.py`: `utils/` (`detzero_utils`, shared),
  `detection/` (`detzero_det`), `tracking/` (`detzero_track`), `refining/` (`detzero_refine`).
- Runtime environment: `docs/INSTALL.md`. Dev tooling: `requirements-dev.txt`.

## Commands (run these exactly)
| Task | Command |
|---|---|
| Install dev tools | `pip install -r requirements-dev.txt` |
| Lint (harness code) | `ruff check tests scripts` |
| Types | `python scripts/mypy_ratchet.py` |
| Tests (CPU) | `python -m pytest -q -m "not slow and not cuda"` |
| House rules | `semgrep scan --config .semgrep/ --metrics=off --baseline-commit origin/main` |
| Git hooks | `pre-commit install` |

Tests need no GPU and no compiled extensions: `tests/conftest.py` puts the packages on
`sys.path` and stubs the CUDA extensions.

## Rules
- Never widen a type to `Any` to silence a type error. Fix the type.
- No blanket `# type: ignore`; use `# type: ignore[code]` plus a one-line reason.
- `.mypy-baseline.json` only goes down. Never run `scripts/mypy_ratchet.py --update` to absorb
  new errors; a human updates it when deliberately accepting legacy debt.
- New geometry/tensor helpers get a test in `tests/`; prefer a Hypothesis property
  (round trip, invariance, bounds) over hand-picked examples.
- Never loosen an `assert_allclose` / `assert_close` tolerance to make a test pass.
- Don't change numerical behaviour in a typing/annotation or refactoring change. If it
  reveals a real bug, report it separately rather than folding the fix in silently.
- No deprecated NumPy aliases (`np.bool`, `np.int`, `np.float`, ...).

## Boundaries (do not touch)
- `data/**`, checkpoints (`*.pth`, `*.pkl`, `*.npy`): do not read, write or commit.
- `utils/detzero_utils/ops/*/src/**` (CUDA/C++): change only when the task says so, and
  only with a GPU available to build and test it.
- `*/version.py` is generated by `setup.py`.

## Done means
All of these pass locally, and you paste their output:
`ruff check tests scripts`, `python scripts/mypy_ratchet.py`,
`python -m pytest -q -m "not slow and not cuda"`.
